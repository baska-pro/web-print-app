# Changelog

All notable changes to the public repository are documented here.

## 4.0.3-advanced

Initial public repository package for the supplied Web Print App / PrintBot WebApp source.

Highlights already present in this version:

- Local Windows printer engine with persistent SQLite queue.
- Windows Spooler status and cancellation support.
- File manager, search, upload/download, preview, rename/delete, and managed roots.
- PDF/image printing plus Microsoft Office COM support for Word, Excel, and PowerPoint.
- A4/F4/Legal/Letter, orientation, scale, duplex, color mode, copies, pages, priority, and scheduled print.
- Admin/user roles, session security, CSRF protection, login throttling, quotas, audit/error logs.
- PWA, SSE realtime updates, browser notifications, backup/restore, maintenance tools, history export.
- Optional Telegram administrator notifications.
- Optional self-update/rollback and Windows Task Scheduler autostart.
